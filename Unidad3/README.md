# Unidad 3

## Proyecto Integrador: Supervivencia de pasajeros del Titanic

Análisis y comparación de cinco algoritmos de Machine Learning supervisado:

- K-Nearest Neighbors (KNN)
- Regresión Logística
- Árbol de Decisión
- Random Forest
- Support Vector Machine (SVM)

**Dataset:** Titanic (Kaggle).

**Herramientas:** Python, Google Colab y Scikit-learn.

**Objetivo:** Comparar el desempeño de los modelos mediante Accuracy, Precision, Recall, F1-score y AUC para predecir la supervivencia de pasajeros.
